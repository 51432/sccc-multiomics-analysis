# sccc-multiomics-analysis

本仓库用于宫颈小细胞癌（SCCC）的多组学分析、分子分型及整合分析相关代码与流程管理。

## 仓库内容

本仓库主要包括以下内容：

- `scripts/`：各类分析脚本
- `data/`：输入数据、整理后的数据及样本信息
- `results/`：分析结果输出
- `figures/`：图表及论文相关图片文件
- `docs/`：分析说明、流程记录及补充文档
- `notebooks/`：探索性分析笔记

## 研究方向

本项目主要围绕以下内容展开：

- 宫颈小细胞癌的多组学特征分析
- 分子分型研究
- 基因组、转录组及其他组学数据整合
- 下游统计分析与可视化展示
